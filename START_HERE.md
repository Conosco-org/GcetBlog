## ❓ Quick Answers

### What is a "slug"?

A slug is a URL-friendly version of a title.

```
Title: "My First Post"  →  Slug: "my-first-post"
```

**Read more:** [QUICK_START.md](./QUICK_START.md#what-is-a-slug)

### How do I create a page?

**Option 1:** Use the admin panel at `/admin`  
**Option 2:** Create a file in `src/app/(frontend)/`

**Read more:** [QUICK_START.md](./QUICK_START.md#how-pages-work)

### What are the user roles?

```
Admin > Editor > Contributor
```

- **Admin:** Can do everything
- **Editor:** Can publish content
- **Contributor:** Can create drafts

**Read more:** [QUICK_START.md](./QUICK_START.md#user-roles)

### Where is the code organized?

```
src/
├── collections/     # Data models
├── access/          # Permissions
├── app/             # Pages
├── blocks/          # Content blocks
└── components/      # UI components
```

**Read more:** [CODEBASE_GUIDE.md](./CODEBASE_GUIDE.md#directory-structure-explained)
